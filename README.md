💉 BioGenesys Lab – Expansión Estratégica de Centros de Vacunación en Sudamérica
BioGenesys Pharmaceutical es un laboratorio multinacional que busca expandir su presencia en América Latina. Fui contratado como Data Analyst para llevar adelante un análisis estratégico que permita identificar ubicaciones óptimas para nuevos centros de vacunación y laboratorios.

🎯 Objetivos del Proyecto
Realizar un Análisis Exploratorio de Datos (EDA) sobre la incidencia de COVID-19 y otros factores relevantes.

Aplicar técnicas de limpieza de datos para garantizar calidad y confiabilidad.

Optimizar procesos de extracción, transformación y carga (ETL).

Desarrollar dashboards interactivos con visualizaciones claras y efectivas.

Proponer ubicaciones estratégicas para la expansión de la empresa en Sudamérica.

🧰 Herramientas Utilizadas
Lenguaje: Python

Editor de código: Visual Studio Code

Librerías principales: Pandas, NumPy, Seaborn, Matplotlib

Visualización y BI: Power BI

Scripts personalizados: Python en Power BI

🗂️ Descripción del Dataset
Fuente: Equipo de Data Engineering de BioGenesys

Tamaño inicial: +12 millones de registros

Reducción:

Filtrado por países (Argentina, Brasil, Chile, México, Perú y Colombia) → ~6,000 registros

Filtrado por fecha (desde 01-01-2021) → ~3,700 registros

Limpieza de datos:

Completado de valores nulos usando promedios de cada columna

📊 Análisis Exploratorio de Datos (EDA)
El análisis inicial se centró en detectar patrones y relaciones entre variables clave mediante:

Heatmap: Para detectar correlaciones significativas

Gráficos adicionales:

Histogramas

Gráficos de densidad

Gráficos de barras

Gráficos de líneas

Gráficos de violín

📈 Dashboard en Power BI
Dataset filtrado y cargado en Power Query

Revisión adicional de outliers y valores faltantes

Visualizaciones principales:

Panorama general de los países analizados

Casos, muertes, vacunación, recuperación por país

Integración de visualizaciones de Python (Seaborn) mediante Scripts

🌎 Enfoque Final: México y Chile
Razones para priorizar estos países:

🇲🇽 México:
Alta población

PBI per cápita significativo

Tendencia creciente de casos

🇨🇱 Chile:
Alta aceptación de vacunas

Buen desempeño económico (PBI per cápita alto)

Infraestructura sanitaria favorable

✅ Conclusiones
La recomendación estratégica es iniciar la expansión en México y Chile por sus condiciones epidemiológicas, económicas y sociales. Estos países representan puntos clave para el desarrollo de nuevos centros de vacunación y laboratorios de BioGenesys en América Latina.

**BioGenesys Pharmaceutical** is a multinational laboratory aiming to expand its operations across Latin America. I was hired as a **Data Analyst** to conduct strategic analysis and identify optimal locations for new vaccination centers and laboratories.

---

## 🎯 Project Objectives

- Perform **Exploratory Data Analysis (EDA)** on COVID-19 incidence and related factors.
- Apply **data cleaning** techniques to ensure quality and reliability.
- Optimize **ETL** (Extract, Transform, Load) processes for better data accessibility.
- Develop **interactive dashboards** for effective data exploration and strategic decision-making.
- Recommend key locations for expansion in South America.

---

## 🧰 Tools & Technologies

- **Language:** Python  
- **Code editor:** Visual Studio Code  
- **Main libraries:** Pandas, NumPy, Seaborn, Matplotlib  
- **Visualization & BI:** Power BI  
- **Custom scripts:** Python in Power BI

---

## 🗂️ Dataset Description

- Provided by: BioGenesys Data Engineering team  
- Initial size: Over 12 million records  
- Filtering process:
  - By country (Argentina, Brazil, Chile, Mexico, Peru, Colombia) → ~6,000 records
  - By date (from 2021-01-01 onwards) → ~3,700 records  
- Null value treatment: Replaced with column averages

---

## 📊 Exploratory Data Analysis (EDA)

Initial analysis aimed to uncover key patterns and relationships using:

- **Heatmap**: For identifying strong correlations  
- **Other charts**:
  - Histograms
  - Density plots
  - Bar charts
  - Line plots
  - Violin plots

---

## 📈 Dashboard in Power BI

- Filtered dataset loaded in Power Query
- Additional review for outliers and missing data
- Key visualizations:
  - Overview of analyzed countries
  - Cases, deaths, vaccinations, recovery
- Python visualizations (Seaborn) embedded via scripts

---

## 🌎 Focus Countries: Mexico and Chile

**Strategic reasons to prioritize these countries:**

### 🇲🇽 Mexico:
- Large population
- Solid GDP per capita
- Increasing case trends

### 🇨🇱 Chile:
- Strong vaccine acceptance
- High GDP per capita
- Favorable health infrastructure

---

## ✅ Conclusions

The strategic recommendation is to begin the expansion in **Mexico and Chile**. These countries offer the best mix of population, economic performance, and health behavior, making them ideal starting points for BioGenesys' growth in Latin America.
